# Invented calibration batch · v1

This batch contains 30 original, fictional English review texts for codebook
calibration. None is copied from a real review or intended for model training.
Give annotators independently randomized item order and opaque IDs; do not provide
an answer key. Each annotator records one label, fired M-patterns, difficulty, and
a short evidence-based rationale on an offline sheet. The team computes three-label
Cohen's kappa only after both sheets are locked.

This English batch does not establish French annotation reliability. Before
annotating the French held-out sample, calibrate both annotators on at least 30
separate invented or licensed French texts under the same blindness and kappa
rules. Keep individual labels and rationales offline.
