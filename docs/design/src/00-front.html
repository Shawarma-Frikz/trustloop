DOCUMENTWhat this charter fixes

This is the visual source of truth for TrustLoop. It defines the identity, the six trust stops, typography, layout, components, states, bilingual behaviour, accessibility, design tokens, and the Figma build. It does not redefine the score, the labels, or the copy — those live in the product decisions and model plan.

Change ruleA charter revision updates this directory and the D20 row in the decision register. It never changes band boundaries or the meaning of a score.

How to use it

DesignersBuild from the tokens and component anatomy, not from a screenshot. The Figma prompt in section 13 is the starting point.
DevelopersUse tokens.css as the only colour and spacing source. Do not sample hex values from the PDF.
ReviewersCheck the state matrix, the bilingual strings, and the non-colour cues before commenting on taste.
The defenseUse section 15 for the report cover and slides. The same rules apply: evidence before decoration.
The one rule

If a visual choice makes the estimate look more certain than the model is, remove it. That includes a gauge with a needle, a percentage ring, a green checkmark, a page-level average, and a colour with no label.
