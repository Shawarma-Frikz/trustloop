Rules

The report cover is a document, not a poster. One mark, one title, one subtitle, one colour block. The petrol spine is the only full-height element; it aligns the cover with the charter and costs one pass of ink.

  • A4, 210 × 297 mm. Petrol spine 14 mm; text block begins at 32 mm; right margin 22 mm.
  • Title in Newsreader 44 pt, left aligned, maximum two lines. The subtitle is 14 pt and never bold.
  • Paper stock, not a dark cover. It prints cleanly on an office printer and still reads as designed.
  • No school logo until one is supplied. Leave the lower right free; do not invent an institutional mark.
  • The French cover is re-set, not translated in place. The French subtitle is longer; the title drops to 40 pt if needed.
If a template is imposed

Keep the spine, the mark, and the type. Drop the rest without argument. A required template is not a design decision; the identity survives in two elements.

What the jury receives

Report

A4, bound or PDF. Claim, method, results, limits. The cover is 15.1; the copy is the product's, not the charter's.

Deck

Nine 16:9 slides, under nine minutes. One sentence per slide; the sequence is 15.5.

Card

A6 handout, one result in four lines. Printed at 100%, never over a real review.

Demo

A prepared page with fixture reviews. No live account, no review text in a slide.

15.3 Charts

A chart in this project has one job: show a distribution or a relationship that a single number would hide. It never turns a page into a score. The same banded rule used in the panel is the default chart; everything else must earn its place.

Bars are counts, not percentages. Direct labels replace a legend. The source line names the set, its size, and the date; “illustrative” would appear here on a template. Never chart the reviews of a single product as if they were a population.

Use

  • The banded rule for one review, with marker and scale.
  • A calibration curve when the model plan validates one.
  • A predicted-band distribution with an explicit n.
  • A confusion matrix with counts and row totals.
  • A horizontal bar chart with direct labels and a zero baseline.

Do not use

  • Gauges, dials, speedometers, or semicircles.
  • Donuts, pies, word clouds, or radar plots.
  • A page score, an average trust score, or a site ranking.
  • Dual axes, 3D bars, gradients, or shadows on data.
  • A number without its band, n, or source.
The one-number test

If a chart communicates a single value, show the value. A gauge adds theatre, not information. The defence should be readable with the projector off.

15.6 Questions to expect

QuestionAnswer
“Is this an AI that detects fake reviews?”No. It estimates whether text patterns resemble manipulation. “Fake” is a claim about intent and truth that the model cannot make.
“Why six bands instead of one percentage?”A percentage invites false precision. The band carries the claim; the score carries the measure; the evidence line carries the limit.
“What happens when it is wrong?”It can be wrong inside a band, and the interface says so. When the input is insufficient, it returns unknown rather than a low score.
“Why is the interface French if the model may not be?”The interface is translated; model coverage is gated per language (D13, D23). The unsupported-language state never implies coverage.
“Why not show a score for the whole page?”An average of reviews would invent a claim the model cannot support. The panel counts reviews; it does not grade the product.
“What do you store?”History is off by default. When enabled: host, time, adapter, status, result, model version — never review text, review keys, or the URL.

A.7 String QA

  • One source. The copy deck is the only place a normative string is edited. Figma, code, and this appendix follow it.
  • Both languages together. A key is not done until English and French exist. No placeholder English in a French frame.
  • No concatenation. Build sentences whole; do not stitch “Band” + number + “of 6” in code, which breaks French word order and pluralisation.
  • No truncation. Test the longest French string at 320 px; the disclaimer and the refresh notice are the stress cases.
  • Numbers and spaces. English “31%”, French “31 %” with a no-break space; scores have no percent sign and no decimal.
  • Punctuation. French uses « guillemets » and a narrow no-break space before : ; ! ?. English uses curly quotes and an em dash without surrounding spaces.
  • Pluralisation. “1 review / 3 reviews”; “1 avis / 3 avis”. Zero takes the plural in both languages.
  • Forbidden words. No “AI”, “fake”, “bot”, “verified”, “confidence”, “accuracy”, “probability”, or “page score” in user-facing copy. The model is described by what it estimates, not by what it is.
The boundary

This appendix documents copy; it does not create it. A proposed string becomes normative only when the copy deck changes, in both languages, with the same claim. Until then, the mockup is a proposal, not a specification.
